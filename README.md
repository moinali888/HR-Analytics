# HR-Analytics

1. Project Title
"HR Analytics Dashboard: Data-Driven Workforce Insights"

2. Project Overview
This dashboard helps HR professionals to analyze employee trends, performance, satisfaction and attrition. These insights are useful for optimizing business decision-making and HR policies.

3. Key Features of Dashboard
- Attrition & Trends – department-wise attrition analysis
- Interactive Filters & Drill-downs – Department-wise, gender-wise
- Counts - Attrition, employee, year, avg salary

4. Tools & Technologies Used
- Data Visualization: Power BI / Power Query

5. Dataset Description
Features Overview:
- Employee ID, Age, Gender, Department, Salary, Performance Score, Attrition, Promotion, etc.
- Data Cleaning & Preprocessing: Handling missing values, outliers, standardization

6. Business Questions Answered
- In which department attrition is the highest?
- What is the relation between performance and salary?
- Which age group or experience level has the highest attrition?
